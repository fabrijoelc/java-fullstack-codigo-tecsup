# Java Fullstack · Código/Tecsup

Colección de **15 proyectos** desarrollados durante el curso Java Fullstack de Código/Tecsup. Reúne aplicaciones con Spring Boot y React, desde APIs REST y consumo de servicios externos hasta arquitectura hexagonal, pruebas y microservicios.

**Tecnologías:** Java · Spring Boot · Spring Cloud · JPA · MySQL · React · Vite · JUnit

## Clonar el repositorio

```bash
git clone https://github.com/fabrijoelc/java-fullstack-codigo-tecsup.git
```

Cada carpeta contiene el código de su proyecto, sin depender de submódulos externos. Consulta su documentación para conocer los requisitos y pasos de ejecución específicos.
